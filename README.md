## 실습 4 : 종합 프로젝트 음악 계획

```
<종합 프로젝트 음악 계획서>

선택 옵션

옵션 1 : 싱글 앨범 제작


---

1. 프로젝트 주제

“Late Night Youth”
청춘의 추억과 우정, 밤 감성을 담은 싱글 앨범 제작


---

2. 앨범 컨셉

늦은 밤 도시를 걸으며 떠오르는 친구, 추억, 미래에 대한 감정을 표현한 감성 K-pop 스타일 앨범이다.
신나는 분위기와 잔잔한 감성을 함께 넣어 청춘 영화 OST 같은 느낌을 목표로 한다.


---

3. 음악 스타일 및 장르

K-pop

Lo-fi Hip-hop

EDM

감성 발라드 요소 혼합


스타일 키워드

dreamy

emotional

energetic

late night city vibe

youth

nostalgic



---

4. 수록곡 계획

1번 트랙 : Stay With Me

장르 : K-pop + Lo-fi

분위기 : 따뜻하고 감성적인 밤 분위기

특징 : 부드러운 피아노와 chill 비트 사용


2번 트랙 : Neon Lights

장르 : EDM + K-pop

분위기 : 화려하고 에너지 넘치는 축제 느낌

특징 : 강한 드롭과 중독성 있는 후렴


3번 트랙 : Rainy Memories

장르 : 발라드 + 재즈

분위기 : 비 오는 밤의 추억 감성

특징 : 피아노와 색소폰 중심의 잔잔한 곡



---

5. 제작 방법

AI 음악 생성 도구를 활용하여 장르별 스타일 적용

Custom Mode를 사용해 직접 작성한 가사 입력

여러 버전 생성 후 가장 완성도 높은 곡 선택

필요 시 Extend 기능으로 아웃트로 추가 예정



---

6. 앨범 커버 아이디어

네온사인이 있는 밤거리에서 이어폰을 끼고 걷는 청춘의 모습
보라색과 파란색 계열의 몽환적인 분위기로 제작 예정


---

7. 기대 효과

다양한 장르를 혼합하는 음악 제작 경험 가능

AI를 활용한 창작 과정 이해

감정과 분위기를 음악으로 표현하는 능력 향상



---

생각해볼 질문 답변

음악 컨셉/테마는?

청춘, 우정, 밤 감성, 추억

장르는?

K-pop, Lo-fi Hip-hop, EDM, 발라드

분위기 키워드는?

감성적, 몽환적, 따뜻함, 청춘 영화 같은 느낌

필요한 곡 목록은?

1. Stay With Me


2. Neon Lights


3. Rainy Memories



연계 가능한 다른 AI 도구는?

이미지 생성 AI : 앨범 커버 제작

영상 생성 AI : 뮤직비디오 및 배경 영상 제작

음성 AI : 보컬 스타일 변경 및 효과 추가
```
